# Java MVC Интернет-магазин

Учебный проект веб-приложения интернет-магазина на Java. Проект сделан по архитектуре MVC и использует Servlets, JSP, Maven и MySQL.

## Что умеет приложение

- Регистрация пользователя
- Вход и выход из аккаунта
- Просмотр каталога товаров
- Просмотр категорий и фильтрация товаров по категории
- Просмотр карточки товара
- Добавление товара в корзину
- Просмотр и очистка отдельных товаров из корзины
- Оформление заказа
- Просмотр истории заказов

## Технологии

- Java 11
- Maven
- Servlet API 4.0
- JSP и JSTL
- MySQL 8
- Apache Tomcat 9
- BCrypt для хэширования паролей

## Структура проекта

```text
src/main/java/com/example/
├── beans/      # Модели данных: User, Product, Category, CartItem, Order, OrderItem
├── dao/        # Работа с базой данных через DAO и PreparedStatement
├── servlets/   # Контроллеры, которые обрабатывают HTTP-запросы
└── util/       # Вспомогательные классы, например PasswordUtil

src/main/webapp/
├── WEB-INF/views/  # Общие JSP-фрагменты header/footer
├── css/            # Стили
└── *.jsp           # Страницы интерфейса

database/init.sql   # Создание базы, таблиц и тестовых данных
```

## Как запустить

### 1. Создать базу данных

Убедитесь, что MySQL запущен, затем выполните:

```bash
mysql -u root -p < database/init.sql
```

Скрипт можно запускать повторно: он пересоздаёт таблицы и добавляет тестовые данные.

### 2. Настроить подключение к MySQL

По умолчанию приложение подключается так:

```text
jdbc:mysql://localhost:3306/online_shop
user: root
password: password
```

Если пароль другой, можно передать параметры при запуске Tomcat:

```bash
-Ddb.user=root -Ddb.password=ВАШ_ПАРОЛЬ
```

Также можно поменять значения в `src/main/java/com/example/dao/DBConnection.java`.

### 3. Собрать проект

```bash
mvn clean package
```

После сборки появится файл:

```text
target/online-shop.war
```

Если команда `mvn` не найдена, нужно установить Maven или открыть проект в IntelliJ IDEA как Maven-проект.

### 4. Запустить в Tomcat

Скопируйте `target/online-shop.war` в папку `webapps` Apache Tomcat и откройте:

```text
http://localhost:8080/online-shop/products
```

## Как объяснить MVC на защите

- `Bean` - обычные Java-классы, которые описывают данные: пользователь, товар, корзина, заказ.
- `DAO` - слой доступа к базе данных. Здесь находятся SQL-запросы и работа с MySQL.
- `Servlet` - контроллер. Он принимает HTTP-запрос, вызывает DAO и выбирает JSP-страницу для ответа.
- `JSP` - представление. Оно показывает HTML-страницу пользователю.

Пример сценария:

1. Пользователь открывает `/products`.
2. `ProductServlet` получает запрос.
3. `ProductServlet` вызывает `ProductDAO` и `CategoryDAO`.
4. DAO получает товары и категории из MySQL.
5. Сервлет передаёт данные в `products.jsp`.
6. JSP выводит каталог в браузере.

## Важные решения

- Пароли не хранятся открытым текстом. При регистрации пароль хэшируется через BCrypt.
- SQL-запросы выполняются через `PreparedStatement`, чтобы безопасно передавать параметры.
- При оформлении заказа используется транзакция: заказ и его товары должны сохраниться вместе.
- Корзина привязана к пользователю, поэтому просмотр корзины и заказов доступен только после входа.

## Проверочный сценарий

1. Открыть каталог.
2. Зарегистрироваться.
3. Войти в аккаунт.
4. Выбрать категорию.
5. Открыть карточку товара.
6. Добавить товар в корзину.
7. Удалить товар из корзины.
8. Добавить товар ещё раз.
9. Оформить заказ.
10. Открыть историю заказов.
11. Выйти из аккаунта.
